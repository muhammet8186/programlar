🚀 HTML → Android APK

Bu sürüm APK'yı Render sunucusunda değil, GitHub Actions üzerinde derler. Böylece sunucuya Android SDK kurmak gerekmez.

GitHub Actions'ı aç

1. HTML dosyanı projeye koy

GitHub deposunda apkolustur/webapp/ klasörünü aç. Kendi HTML uygulamanı index.html adıyla bu klasöre yükle. HTML'in kullandığı CSS, JS ve görseller de aynı webapp klasöründe, klasör yapıları korunarak bulunmalı.

2. APK derlemesini başlat

1

GitHub'da Actions sekmesini aç.

2

Soldan HTML to Android APK iş akışını seç.

3

Run workflow düğmesine bas. Uygulama adını ve paket kimliğini yaz (ör. com.muhammet.radyo).

4

Run workflow ile başlat. İşlem birkaç dakika sürebilir.

3. APK'yı indir

Derleme yeşil tik ile tamamlanınca çalıştırma sayfasını aç. Sayfanın altındaki Artifacts bölümünden android-debug-apk dosyasını indir. ZIP içindeki app-debug.apk dosyasını Android telefonuna kur.

Bilmen gerekenler

Bu, test amaçlı debug APK üretir. Play Store yayını için imzalı release/AAB, uygulama ikonu ve gizlilik politikası ayrıca hazırlanmalıdır. HTML dosyanın internet gerektiren işlevleri APK içinde de internet gerektirir.
